# Módulos backend

Los paquetes de cada módulo reservan las responsabilidades aprobadas:

- `controller`: endpoints HTTP y mapeo de solicitudes/respuestas.
- `service`: reglas y coordinación de casos de uso.
- `repository`: acceso a persistencia.
- `entity`: modelo persistente.
- `dto`: contratos de entrada y salida de la API.

Las carpetas contienen solo marcadores en esta etapa. No se han añadido todavía entidades, autenticación funcional ni lógica de negocio.
